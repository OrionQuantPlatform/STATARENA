Private read-only input. Use the two immutable copied TSVs (411,416 stored metric rows cumulatively). No AWS reads or mutations. Compare actual PostgreSQL 18 relation allocation including all proof indexes, after bulk loading the same rows. Prove exact native 004 typed-row equality in both SQL EXCEPT ALL directions, retaining missing/null distinctions, dynamic source labels and source item positions. Encode shared field labels, types and presence as normalized dictionaries and ordered template membership. Store observed semantic measures in named numerical columns. Unexpected keys, repeated semantic keys in one map, and values outside the inferred lossless narrow type use a separate relational overflow table. A wide column itself never determines whether the source key was present; template flags do. Measure original vs new allocation and elapsed cold/warm per-resource aggregation with identical JSON values; separate proof of the two measured metric families from a whole-database forecast. Adversarial tests cover duplicate semantic keys, unknown labels, zero, null, omitted fields, rare noninteger values, out-of-range numbers and sparse ordinal sequences. Physical publication and concurrent updates require independent verification prior to production.

The default corpus is the four checked-in COPY archives in ../inputs/. Both the compressed and decoded SHA-256 fingerprints and row counts are in its manifest.json. Set METRIC_COPY_INPUT to select a separate fixture directory. The runners forward it to the isolated Python child.
