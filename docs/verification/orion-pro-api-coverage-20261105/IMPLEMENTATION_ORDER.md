Orders2–5 can be split by smallest complete contract and scheduled after the required data is qualified. They are not a promise that every native schema gap requires a new table; evaluate current destinations and prove missing grain/state/uniqueness first. The107 amendment's four structural children are not applied or assumed by this plan.

Compatibility rule: retain the existing summary-v1-shots-v1 implementation for its published tokens. The next capability bundle needs an explicit supported representation/adaptor version and closure contract; do not silently populate V1 empty fields, change its source-profile priority or rotate coordinates. Current metadata reader rejects unrecognized representation_version, so new adapters require deliberate dispatch rather than merely changing a build label.

Multi-edition caveat: the reader's internal proset hash binds the currently selected token set for ETag/cursor checks, but the validator accepts only pro1 build tokens and the UI intentionally requires one edition. proset is not a round-trippable immutable multi-edition URL. The mutable catalogue singleton cannot prove historical global publication on its own. Until a separately reviewed contract exists, keep global discovery explicitly mutable and use edition tokens for frozen requests; no new generic registry/history is introduced here.

The fallback guard supplies an actionable501 for current unsupported capabilities and prevents hidden mixing during this work. The parity matrix must ultimately close every intended screen/route with accepted data and contracts, not declare those rows complete because a refusal works.
