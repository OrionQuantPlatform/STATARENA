# Protocoles avant intégration

Ces textes originaux et leurs sorties statiques historiques sont conservés inchangés. Les protocoles courants gardent leurs assertions de première application mais reconstruisent leur entrée temporaire au bon stade du générateur. Le modèle final déjà transformé ne constitue pas une entrée valide du helper de contraintes universelles retirées. Ces preuves concernent uniquement la structure en mémoire ; aucun SQL ni service n’a été exécuté.
